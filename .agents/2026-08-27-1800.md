## Errors and Lessons
- `layout: elk` does not apply to `C4Container` (Mermaid C4 has fixed grid; only `UpdateLayoutConfig($c4ShapeInRow, $c4BoundaryInRow)` and statement order matter, and `@mermaid-js/layout-elk` is not bundled on GitHub). Verified via `viewBox` and `mermaid.ai/open-source/syntax/c4.html` (experimental).
- `UpdateLayoutConfig` requires `$`-prefixed quoted form (`$c4ShapeInRow="4"`) — `UpdateLayoutConfig(4, 1)` without `$`/quotes fails to parse when `c4: wrap` frontmatter is present.
- `c4: wrap: true` frontmatter is the supported C4 knob for long labels (wraps by default since 11.17.1).
