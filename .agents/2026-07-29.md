- **MutationObserver for `target="_blank"` abandoned**  ---  NiceGUI's Vue reactivity resets `innerHTML` after JS patches, stripping added attributes. Server-side raw HTML approach also abandoned because it interferes with markdown2's link parsing and generates ugly output.

The `\n\n` between `</p>` and `<ul>` rendered as visible blank lines regardless of margin values. Took a while to identify because `margin` was the obvious suspect.
- **Vue reactivity vs. DOM patching**  ---  MutationObserver modifications to `innerHTML` (adding `target="_blank"`) are overwritten by NiceGUI's Vue lifecycle when it re-renders. Server-side HTML injection (`<a>` tags in markdown source) works but markdown2 emits ugly output for already-linked content. Skipped for now.
