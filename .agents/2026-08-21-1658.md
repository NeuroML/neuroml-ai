## Errors and Lessons

- LangChain `ChatPromptTemplate` inserts substituted variables literally
  (no `{}` rescans), so prompt values must NOT be brace-escaped -- verified
  empirically after an initial (wrong) escaping attempt.
- Doubling braces only matters for literal template *text* (e.g.
  `_format_output_schema_prompt`).
- Pre-existing baseline in the repo is tolerated: ruff CI uses
  `--exit-zero`; `ty` already reports ~24 diagnostics (override
  signature-narrowing in nodes, `RUF012` `model_defaults`,
  `RUF059` unpacked tuple vars).  None introduced by Task A.
- `ruff check . --fix` on agent_pkg auto-reordered imports in 7 node files
  (pre-existing tidy, unrelated to the feature).
- `k*3` BM25 post-filter and native vector filters mean a filter on a
  missing metadata key prunes that store to zero -- the reasoning that led
  to config-only field surfaces and per-domain routing.
- typer/rich colorise `--help`: ANSI is inserted *between* the dashes of
  `--debug`, so "raw output contains --debug" assertions break.  `NO_COLOR`
  loses to `FORCE_COLOR` in rich, but `TERM=dumb` wins; `CliRunner(color=...)`
  does NOT strip typer/rich output.
- sqlite: python `sqlite3.execute()` itself refuses multi-statement
  (ProgrammingError) -- a second layer beyond our validator against
  `...; DROP ...`; progress-handler aborts surface as "interrupted".  The
  tool's result dict must carry `error` (empty) on success too; permission
  gate denies tmp_path outside cwd, so tests pass `project_root`.
