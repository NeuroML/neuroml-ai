## Objective

Add framework-agnostic functions to `klea_utils` that list the files of
archival repositories (GitHub, FigShare, DANDI, BioModels) so osb-mcp (a
separate repo) can wrap them into per-source MCP tools, plus a multi-file
download helper.  Modelled on the OSBv2 repository adapters.

## Completed

- New `klea_utils/mcp/tool_impls/repositories/` subpackage:
  - `sources.py` - `_get_json` (honest UA, shared retryer, SSRF guard)
  - `errors.py` - `RepositorySourceError`
  - `github.py`, `figshare.py`, `dandi.py`, `biomodels.py` - each provides
    `*_list_versions` and `*_list_files`, returning a uniform
    `{source, url, version, versions, files, error}` schema where every
    file entry carries `path`, `name`, `download_url`, `size`.
- `download_files` in `download_file.py`: bounded-concurrency
  (`asyncio.Semaphore`) multi-file downloader that drives `download_file`
  into a caller-chosen `target_dir`, continue-on-error with per-file
  results (`saved_to` or `error`).
- Tests in `test_osb_sources.py` (mock + live, live self-skips when the
  API is unreachable) and `TestDownloadFiles` in `test_bundled_tools.py`.
- Five commits, one per deliverable (github / figshare / dandi / biomodels
  / download_files).

## Decisions

- Dropped OSB jargon: `context` -> neutral `version` (GitHub docs that a
  version is a branch/tag; figshare/dandi/biomodels versions map naturally).
- Removed URL-sniffing dispatch (`detect_source`): osb-mcp tools will be
  per-source (`list_github_files`, ...), so the LLM already knows the source.
- FigShare URL parsing is deliberately soft (any host, trailing numeric
  article ID) because institutional instances sit on arbitrary domains;
  the API is always the shared `api.figshare.com/v2`.
- DANDI walk is a BFS over `assets/paths` (page/page_size pagination) with
  a total-file cap; asset download URLs use the 302-redirect endpoint.
- BioModels has migrated from `www.ebi.ac.uk/biomodels` to
  `www.biomodels.org` (legacy host redirects); supports both `MODEL...`
  and `BIOMD...` ids.  Example/test model: `BIOMD0000000001`.
- GitHub live test compares a curated `STABLE_REPO_FILES` subset
  (AGENTS.md + setup.cfg files) rather than the full tree, so it is not
  broken by un-pushed local files.
- Live tests are not marked `localonly` (self-skip makes them CI-safe).
- `repositories/__init__.py` carries no `__all__`/re-exports - import from
  specific modules (convention added to AGENTS.md files).
- `download_files` uses `download_file` (not `download_file_to_cache`) so
  `target_dir` is an explicit destination (project root or cache), not the
  app cache.
