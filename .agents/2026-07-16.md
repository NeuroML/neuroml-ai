## Errors and Lessons

- Initial implementation had circular dependency between app.py and runner.py - fixed by moving all UI logic to runner.py
- Removed unused global `_config` dict and `get_config()` function - configuration should be passed via function parameters
- Removed duplicate `@ui.page("/")` decorators - only one should exist in the application
- NiceGUI requires `storage_secret` parameter in `ui.run()` to use `app.storage.user` for session persistence

## Open Questions

  - `GET /sessions/{session_id}/history` - fetch conversation history

- LangGraph stores history in checkpoints but no API exists to access it
- Multi-user support requires per-user RAG/KleaCode instances with different model configurations
