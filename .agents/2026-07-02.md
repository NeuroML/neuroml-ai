## Errors and Lessons

- Content-block list format from langchain-ollama crashed `split()` / `strip()` in
  three places (AnswerGeneral, GenerateRetrievalQuery). Fixed by extracting text
  from list content blocks before string operations.
- `from contextlib import chdir` available in Python 3.11+ -- worked at runtime
  but confused the LSP.
- `aiter_lines()` on httpx streaming responses works but is not prominently
  documented -- added comment to test.
- SSE error events were silently ignored by both frontends -- added handling.
- Node timestamps from yaspin's `timer=True` are misleading (show total elapsed,
  not per-node duration). Per-node timing now logged server-side instead.
