## Errors and Lessons

- NiceGUI: creating UI elements from a bare `background_tasks.create(...)`
  task fails ("slot stack is empty"). Pass async handlers directly as
  `on_click=`; NiceGUI's event dispatch runs them inside the sender's slot
  context. For background-task UI, enter an existing slot explicitly with
  `with container_element:`.
- NiceGUI `app.storage.user` is only guaranteed valid in the initial request
  context of an async page builder -- touch it before the first `await`.
- A `setup_layout` parameter captured by closures is shared by reference;
  `nonlocal user_id` + rebind switches the whole page session's identity
  without threading a mutable holder through 38 call sites.
- The "delete user session" flow must check the DELETE status code; non-200
  means the server data is still intact, so aborting beats minting a new user.
- Session isolation for tests: I initially ran `pytest` from the repo root and
  got ~24 errors; per-package runs (as CI does via `scripts/run_tests.sh`) are
  all green. No real test failures exist.
- `sphinx-build -W`/`-D`/`-T` are not accepted in this Sphinx 9.1.0 install's
  CLI path (`-W` worked only as `-W` on the `sphinx` subcommand form); use
  `sphinx-build docs docs/_build` and pass `-D exclude_patterns=...` to work
  around the typer break, or exclude_patterns via conf.
